**Format**: `.apr` (Aprender Portable Runtime) for test artifacts

---

## Executive Summary

This specification defines the requirements for WOS to achieve **100% Probador compliance** — a pure Rust browser testing framework that eliminates JavaScript entirely. WOS v2.0 has achieved **Zero JavaScript** in the application layer; this document extends that mandate to testing.

**Key Goals**:
1. Replace all JavaScript-based E2E tests with Probador
2. Implement TUI testing via `jugar-probar` with `tui` feature
3. Add pixel-perfect visual regression testing
4. Create declarative playbooks for deterministic replay
5. Achieve 100% GUI coverage via Probar framework

## Implementation Plan

### Phase 1: TUI Testing (jugar-probar)

**Goal**: Test terminal UI components in pure Rust

**Files to Create**:
```
wos/tests/probar_terminal.rs     # Terminal component tests
wos/tests/probar_panels.rs       # Panel switching tests
wos/tests/probar_commands.rs     # Command execution tests
```

**Example Test Structure**:
```rust
//! WOS Probar TUI Tests
//!
//! Pure Rust terminal UI testing via jugar-probar

use jugar_probar::prelude::*;
use wos::WosWasm;

/// Terminal Page Object
#[derive(Debug, Clone)]
pub struct TerminalPage {
    input: Locator,
    output: Locator,
    prompt: Locator,
}

impl TerminalPage {
    pub fn new() -> Self {
        Self {
            input: Locator::from_selector(Selector::css("#terminal-input")),
            output: Locator::from_selector(Selector::css("#terminal-output")),
            prompt: Locator::from_selector(Selector::css(".terminal-prompt")),
        }
    }
}

#[probar_test]
async fn test_terminal_echo() -> ProbarResult<()> {
    let page = TerminalPage::new();

    // Type command
    page.input.fill("echo hello").await?;
    page.input.press("Enter").await?;

    // Verify output
    let output = page.output.text_content().await?;
    assert!(output.contains("hello"));

    Ok(())
}

#[probar_test]
async fn test_command_history() -> ProbarResult<()> {
    let page = TerminalPage::new();

    // Execute commands
    page.input.fill("ls").await?;
    page.input.press("Enter").await?;
    page.input.fill("ps").await?;
    page.input.press("Enter").await?;

    // Navigate history
    page.input.press("ArrowUp").await?;
    assert_eq!(page.input.input_value().await?, "ps");

    page.input.press("ArrowUp").await?;
    assert_eq!(page.input.input_value().await?, "ls");

    Ok(())
}
```

### Phase 3: Playbooks (.apr Format)

**Goal**: Declarative test scenarios for deterministic replay

**Files to Create**:
```
wos/tests/playbooks/
├── smoke-test.apr           # Basic functionality
├── vim-workflow.apr         # Vim editor tests
├── process-management.apr   # ps, kill, fork tests
├── file-operations.apr      # ls, cat, mkdir tests
└── accessibility.apr        # WCAG compliance
```

**Playbook Format**:
```yaml
# smoke-test.apr
version: "1.0"
name: "WOS Smoke Test"
description: "Basic functionality verification"

setup:
  url: "http://localhost:8000"
  wait_for: "#terminal-input:enabled"

scenarios:
  - name: "Terminal Ready"
    steps:
      - action: wait_for_selector
        selector: "#terminal-output"
      - action: assert_text
        selector: "#status"
        contains: "Ready"

  - name: "Help Command"
    steps:
      - action: fill
        selector: "#terminal-input"
        value: "help"
      - action: press
        key: "Enter"
      - action: assert_text
        selector: "#terminal-output"
        contains: "Available commands"

  - name: "Process List"
    steps:
      - action: fill
        selector: "#terminal-input"
        value: "ps"
      - action: press
        key: "Enter"
      - action: assert_text
        selector: "#terminal-output"
        contains: "PID"

  - name: "Panel Switching"
    steps:
      - action: click
        selector: "[data-panel='process_list']"
      - action: assert_visible
        selector: "#panel-process-list"
      - action: click
        selector: "[data-panel='system_monitor']"
      - action: assert_visible
        selector: "#panel-system-monitor"

teardown:
  - action: screenshot
    path: "artifacts/smoke-test-final.png"
```
